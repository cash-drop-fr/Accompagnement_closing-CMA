DSA — site de formation
========================

Fichiers :
- index.html
- styles.css
- script.js

Utilisation :
1. Mets les 3 fichiers dans le même dossier.
2. Ouvre index.html dans un navigateur.
3. Pour publier sur GitHub Pages, Vercel ou Netlify, envoie le dossier tel quel.

Le site comprend :
- 4 thèmes : noir, blanc, violet, hacker
- responsive mobile/PC
- 5 parties
- 13 ressources closing
- lexique marketing
- tuto Beacons
- tableau de vocabulaire valorisant
- bouton de copie du message final
- liens vers les ressources fournies

Note : l'image exacte de ta page Beacons n'a pas été copiée dans le code. Le site contient un aperçu de couverture que tu peux remplacer par ton propre visuel de vente.
